SEES:4100 | Week 01 | 9
Reproducibility

What Reproducible Means

The definition

  • Same data + same code = same figures and numbers
  • Without asking the author anything
  • Verifiable by a stranger, or by you in a year

The counterexample

final_analysis_v3_REALLY_FINAL.xlsx on a laptop desktop, edited by hand, author graduated in May.

SEES:4100 | Week 01 | 10
Reproducibility

The Course in One Relationship

result = analysis(data, code)
data = archived raw observations
code = every processing step, recorded
analysis = runs start to finish, no hands
result = figures anyone can regenerate
  • If any input is missing, the result is an anecdote
  • The project folder keeps all of them together

The Cell That Opens Every Lab

from pathlib import Path

PROJECT_ROOT = Path.cwd()
while not (PROJECT_ROOT / "data").exists() and PROJECT_ROOT != PROJECT_ROOT.parent:
    PROJECT_ROOT = PROJECT_ROOT.parent

DATA_DIR = PROJECT_ROOT / "data"
print(f"Project root: {PROJECT_ROOT}")
  • Finds the project folder no matter where the notebook opens
  • If it prints False for the data folder, stop and fix paths first

SEES:4100 | Week 01 | 16
Reproducibility

The Ritual: Restart and Run All

  • Kernel > Restart Kernel and Run All Cells
  • Re-executes the whole notebook from nothing
  • Catches hidden state from cells run out of order
  • Do it before every submission, all semester
SEES:4100 | Week 01 | 17
Pause & Think

Concept Check

Your notebook works when you run cells in the order you wrote them, but fails on Restart and Run All. What happened, and why does the grader care?

A cell depended on state from a deleted or reordered cell
The grader always runs fresh: if it fails fresh, it fails
SEES:4100 | Week 01 | 18
Studio Culture

How to Succeed Here

Bring evidence

The next Lab starts with student reports of solved or unresolved problems. Error messages, values, and tiny tests help the class reason together.

Read errors bottom-up

The last line names the problem. Error messages are information, not verdicts.

Check one number

Verify one value by hand before trusting a table of thousands.
