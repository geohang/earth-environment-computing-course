Motivation

Why Names and Units Matter

A famous failure

  • 1999: Mars Climate Orbiter lost
  • One team used newton-seconds, another pound-seconds
  • No error message, just a missing spacecraft

Your defense

  • temp_c, not x
  • elevation_ft, not elev2
  • Units in the name = errors visible at a glance
Earth & Environmental Computing | Week 02 | 3
Core Concept

Variables Are Named Values

temp_c = -2.1                      # daily mean, deg C
temp_f = temp_c * 9 / 5 + 32       # unit conversion
station_id = "IOW"                 # text, not a number

print(temp_c, temp_f, station_id)
  • A good name states what and in which unit
  • Types differ: numbers compute, strings label
Earth & Environmental Computing | Week 02 | 4
Core Concept

Types Decide What Operations Mean

>>> 3 + 4
7
>>> "3" + "4"
'34'
>>> "elevation: " + 204.0
TypeError: can only concatenate str (not "float") to str
  • The same + does different work on different types
  • This TypeError will be the most common message this week
Earth & Environmental Computing | Week 02 | 5
Core Concept

F-strings: Values into Sentences

f"Daily mean: {temp_c:.1f} deg C"
f"..." = formatted string literal
{temp_c} = insert the variable's value
:.1f = one decimal place, fixed point
deg C = the unit, written by you
  • Scientific communication in one line: value, precision, unit

Core Concept

Lists Hold Ordered Data

week_temps = [-2.1, -4.9, -1.3, 0.8, 2.4, 1.1, -0.6]

week_temps[0]      # -2.1   first item
week_temps[-1]     # -0.6   last item
week_temps[1:4]    # [-4.9, -1.3, 0.8]   three items, not four
  • Counting starts at zero
  • A slice [1:4] stops BEFORE index 4
Earth & Environmental Computing | Week 02 | 8
Core Concept

Lists Come with Built-in Tools

  • sum(week_temps) adds everything
  • len(week_temps) counts items
  • max(week_temps), min(week_temps) find extremes
  • sum / len = a mean you computed yourself

Worked Example

Two Routes to One Number

Given

Seven daily mean temperatures from the first week of the record.

Solve

Route 1: sum(temps) / len(temps). Route 2: pandas .mean() on the same column.

Interpret

Both give the same value. Two independent routes agreeing is your first correctness test.

Core Concept

Dictionaries Hold Labeled Data

station = {
    "id": "IOW",
    "latitude": 41.64,
    "longitude": -91.54,
    "elevation_m": 204.0,
}

station["elevation_ft"] = station["elevation_m"] * 3.28084
  • Access by name, not by position
  • New derived entries can be added any time
Earth & Environmental Computing | Week 02 | 11
Core Concept

Looping over a Dictionary

for key, value in station.items():
    print(key, "=", value)

# id = IOW
# latitude = 41.64
# longitude = -91.54
# elevation_m = 204.0
# elevation_ft = 669.29
  • .items() hands you each pair in turn
Earth & Environmental Computing | Week 02 | 12
Visual Summary

List or Dictionary?

List

Ordered sequence. Ask by position: temps[0]. Seven days of temperature.

Dictionary

Labeled storage. Ask by name: station["id"]. One station's metadata.

Rule of thumb

Which one? Ask how you would request an item: by position, list; by name, dict.

Pitfalls

The Errors You Will Meet This Week

  • TypeError: adding a string to a number (fix: f-string)
  • IndexError: asking for temps[7] in a 7-item list
  • KeyError: station["elevation"] when the key is elevation_m
  • Silent wrong factor: a conversion that runs and lies
Earth & Environmental Computing | Week 02 | 16
Pitfalls

Sanity Anchors for Conversions

  • Room temperature: about 20 deg C = 68 deg F
  • A 10 m/s wind: about 22 mph
  • Iowa City elevation: about 200 m = 670 ft
  • A converted number that breaks intuition means a wrong factor
