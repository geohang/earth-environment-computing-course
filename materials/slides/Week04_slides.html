Functions

Anatomy of a Function

CFS_TO_M3S = 0.028316846592

def cfs_to_m3s(discharge_cfs):
    """Convert discharge from cubic feet per second to cubic metres per second."""
    return discharge_cfs * CFS_TO_M3S

q = cfs_to_m3s(1240.0)
print(f"1240 cfs = {q:.2f} m3/s")
  • def starts the definition, and the name follows
  • The names in parentheses are parameters, filled in at call time
  • The indented block is the body, four spaces on every line
  • return hands one value back and ends the call

Functions

Return, Not Print

def mean_flow_printed(df):
    print(df["discharge_cfs"].mean())    # prints, returns None

def mean_flow(df):
    return df["discharge_cfs"].mean()    # returns a usable value

print("printed version handed back:", mean_flow_printed(stream))
flow = mean_flow(stream)
print(f"returned version: {flow:.1f} cfs = {cfs_to_m3s(flow):.1f} m3/s")
  • The printed version hands back None, and the next line fails on it
  • The returned value keeps flowing through the program
  • If a later cell gets None, look for a function that prints instead of returns

Functions

Positional and Keyword Arguments

def sample_id(site, lat, lon):
    return f"{site}_{lat:.2f}_{lon:.2f}"

# positional: order is everything
print(sample_id("IOWARIVER", 41.66, -91.53))

# keyword: order stops mattering
print(sample_id(lon=-91.53, site="IOWARIVER", lat=41.66))

# swapped, and Python cannot tell
print(sample_id("IOWARIVER", -91.53, 41.66))
  • Positional arguments are matched left to right
  • Keyword arguments are matched by name and may appear in any order
  • Keywords must follow positionals in a call
  • Use keywords for anything a reader could confuse: coordinates, depths, thresholds
The third call puts the station in Kazakhstan. No error, no warning.

Functions

Default Arguments

def mean_flow_by(df, date_col="date", flow_col="discharge_cfs", freq="Y"):
    """Mean discharge grouped by period. Returns a Series indexed by period."""
    out = df.copy()
    key = out[date_col].dt.to_period(freq).astype(str)
    return out.groupby(key)[flow_col].mean()

print(mean_flow_by(stream).head(3))          # yearly, the default
print(mean_flow_by(stream, freq="M").head(3))  # monthly, one keyword changed
  • A default makes a parameter optional; callers override only what they need
  • Parameters with defaults come after those without
  • This is the signature style used throughout src/earthcourse/hydro.py
  • Defaults are evaluated once, when the def line runs, which is the next slide

Functions

The Mutable Default Trap

def add_site_buggy(name, sites=[]):        # one list, shared forever
    sites.append(name)
    return sites

def add_site(name, sites=None):            # a fresh list every call
    sites = [] if sites is None else sites
    sites.append(name)
    return sites

print("buggy:", add_site_buggy("Clear Creek"), add_site_buggy("Rapid Creek"))
print("fixed:", add_site("Clear Creek"), add_site("Rapid Creek"))
  • Never put a list, dict, or set in a default; use None and build it inside
  • The default object is created once, when Python reads the def line

Functions

Variable Scope

FREEZING_C = 0.0                       # global

def days_at_or_below_freezing(temps):
    count = 0                          # local to this call
    for t in temps:
        if t <= FREEZING_C:            # reads the global, cannot rebind it
            count += 1
    return count

n = days_at_or_below_freezing(weather["temp_min_c"])
print(f"{n} of {len(weather)} Iowa City days at or below freezing")
  • Names created inside a function are local and exist only during the call
  • A function can read a global name but cannot rebind one by assignment
  • Pass data in as arguments and hand results back with return
  • Globals as shared state are a debugging tax you pay later

Collecting Arguments with *args and **kwargs

def mean_of(*values):                  # values arrives as a tuple
    return sum(values) / len(values)

print(mean_of(2.1, 3.4, 2.8))
print(mean_of(*stream["discharge_cfs"].head(5)))    # unpack at the call

def plot_flow(df, **style):            # style arrives as a dict
    fig, ax = plt.subplots(figsize=(7, 2.2))
    ax.plot(df["date"], df["discharge_cfs"], **style)   # and unpacks again
    ax.set_ylabel("Discharge (cfs)")

plot_flow(stream.head(365), color="steelblue", linewidth=0.8)
  • *args collects extra positional arguments into a tuple
  • **kwargs collects extra keyword arguments into a dict
  • The same stars unpack at the call site, which is how you forward options to a library

Docstrings

def seven_day_low(df, flow_col="discharge_cfs"):
    """Lowest 7-day rolling mean discharge, in cubic feet per second.

    Parameters
    ----------
    df : daily record, one row per day
    flow_col : name of the discharge column (cfs)
    """
    return df[flow_col].rolling(7).mean().min()

print(f"Lowest 7-day mean: {seven_day_low(stream):.1f} cfs")
help(seven_day_low)
  • A string as the first statement of the function, in triple quotes, one summary line
  • State the units of every argument and of the return value
  • help() prints it back to you, and so does hovering in your editor

Type Hints

from pathlib import Path

def peak_above(df: "pd.DataFrame", threshold_cfs: float = 10000.0) -> int:
    """Count days whose discharge exceeds a threshold."""
    return int((df["discharge_cfs"] > threshold_cfs).sum())

print("Days above 10000 cfs:", peak_above(stream))
print("Annotations:", peak_above.__annotations__)
  • Annotations say what goes in and what comes out
  • Python does not check them at run time; your editor does, before you run anything
  • src/earthcourse/hydro.py uses them: cfs_to_m3s(discharge_cfs: float) -> float
  • Hints plus a docstring is the whole contract of a function in five lines

Write the Test Before You Trust

def annual_mean_flow_simple(df):
    """Annual mean discharge (cfs) from daily data."""
    data = df.copy()                   # never mutate the caller's table
    data["year"] = data["date"].dt.year
    return data.groupby("year", as_index=False)["discharge_cfs"].mean()

tiny = pd.DataFrame({"date": pd.to_datetime(["2020-01-01", "2020-01-02", "2021-01-01"]),
                     "discharge_cfs": [10.0, 20.0, 40.0]})
got = annual_mean_flow_simple(tiny)
assert got.loc[got["year"] == 2020, "discharge_cfs"].iloc[0] == 15.0   # (10+20)/2
print(got)
  • Write the test first and state the expected answer out loud: (10 + 20) / 2 = 15
  • assert makes the check permanent, not a one-time glance
  • df.copy() keeps the caller's table untouched

Silent Bugs

The Bug With No Traceback

coerced = pd.to_numeric(raw[FLOW_COL], errors="coerce")
print("rows            :", len(coerced))
print("NaN after coerce:", int(coerced.isna().sum()))
print(f"mean with coerce: {coerced.mean():.2f} cfs")
print(f"true mean       : {stream['discharge_cfs'].mean():.2f} cfs")

# A naive filter that also fails: '14n' starts with a digit
kept = raw[FLOW_COL].str.match(r"^-?\d", na=False)
print("rows kept by a starts-with-a-digit filter:", int(kept.sum()), "of", len(raw))
  • Identical to the true mean, so nothing looks wrong at all
  • errors='coerce' turns a loud failure into a silent one
  • The obvious filter does not help: '14n' starts with a digit
  • scripts/clean_data.py drops the row whose values end in s or d instead
A function that checks its own assumptions turns a silent wrong answer into a loud one.

Silent Bugs

The Unit Bug That Raises Nothing

def cfs_to_m3s_buggy(discharge_cfs):
    """Convert cfs to m3/s. This version has a bug on purpose."""
    return discharge_cfs * 0.28316846592

print(f"Buggy   : 1000 cfs -> {cfs_to_m3s_buggy(1000.0):.1f} m3/s")
print(f"Correct : 1000 cfs -> {cfs_to_m3s(1000.0):.1f} m3/s")
print()
print("What the data itself says:")
print(stream[["discharge_cfs", "discharge_m3s"]].head(3).to_string(index=False))
  • Memorize one anchor per conversion: 1 cfs is about 0.028 m3/s
  • So 1000 cfs must be about 28 m3/s, not 283
  • The discharge_m3s column agrees with the anchor, not with the bug
  • No traceback will ever find this one; only a reader who knows the units will

From print() to logging

import logging
logging.basicConfig(level=logging.DEBUG, format="%(levelname)s %(message)s")

def read_gauge(path, flow_col):
    table = pd.read_csv(path, sep="\t", comment="#", dtype=str)
    logging.debug("rows read = %d", len(table))
    if any(str(v).endswith(("s", "d")) for v in table.iloc[0]):
        logging.warning("dropping USGS type row: %s", table.iloc[0].to_list())
        table = table.iloc[1:].reset_index(drop=True)
    logging.info("returning %d clean rows", len(table))
    return table.assign(discharge_cfs=table[flow_col].astype(float))
  • One switch, the level, turns all of it on or off; you never delete the lines
  • DEBUG to trace, INFO for progress, WARNING for suspicious data, ERROR for failure
  • The 79 estimated values are exactly the kind of thing a WARNING should surface
  • Add filename= to keep a record of a long processing run

def test_type_row_is_dropped():
    table = read_gauge(RAW_GAUGE, FLOW_COL)
    assert table["discharge_cfs"].iloc[0] == 1050.0

Debugging

A Debugging Checklist

  • Read the whole traceback, bottom line first
  • Say out loud what you expected and what happened
  • Check the types, not just the values
  • Shrink the input until the failure is two lines long
  • Change one thing at a time, and re-run
  • Keep the failing case as a test once it passes
  • Before you believe a converted number, check it against an anchor
