Motivation

The Cost of Copy-Paste Analysis

The pattern

  • Same calculation pasted into three cells
  • A bug gets fixed in one copy
  • The other two keep it, silently

The fix

  • One function: one home for the calculation
  • One place to fix, one thing to test
  • Reuse becomes a call, not a paste

Core Concept

Anatomy of a Function

def annual_mean_flow_simple(df):
    """Annual mean discharge (cfs) from daily data."""
    data = df.copy()
    data["year"] = data["date"].dt.year
    return data.groupby("year", as_index=False)["discharge_cfs"].mean()
  • def names it, parameters feed it, return hands the answer back
  • The docstring states units in and units out
  • df.copy() keeps the caller's table untouched

Core Concept

Return, Not Print

result = my_function(data) # result exists, work continues
return value = feeds the next calculation
print output = pixels for humans, then gone
a printing function returns None
None breaks every downstream cell
  • If a later cell gets None, look for a function that prints instead of returns

The Habit

Write the Test Before You Trust

tiny = pd.DataFrame({
    "date": pd.to_datetime(["2020-01-01", "2020-01-02", "2021-01-01"]),
    "discharge_cfs": [10.0, 20.0, 40.0],
})
result = annual_mean_flow_simple(tiny)
assert result.loc[result["year"] == 2020, "discharge_cfs"].iloc[0] == 15.0
  • Three rows, answer computable in your head: (10+20)/2 = 15
  • assert makes the check permanent, not a one-time glance

The Habit

Strength of Evidence

  • Weak: the code ran without errors
  • Better: a tiny test with a hand-checked answer passes
  • Strong: two independent implementations agree on real data
  • np.allclose(mine, package) is the agreement check

Debugging

Tracebacks: Read from the Bottom

Traceback (most recent call last):
  File "...", line 12, in <module>
    print(weather["temp_mean"])
  ...
KeyError: 'temp_mean'
  • Bottom line: what went wrong (a missing column name)
  • Lines above: where it happened
  • Fix: check weather.columns, the name is temp_mean_c

Debugging

The Debugging Ladder

1

Read

The bottom line of the traceback names the problem.

2

Print

Show the intermediate value where things last made sense.

3

Shrink

Run the function on tiny data with a known answer.

4

Compare

Check against an independent implementation.

Silent Bugs

The Worst Bugs Raise Nothing

The planted bug

def cfs_to_m3s_buggy(q): return q * 0.28316846592 1000 cfs -> 283 m3/s ??

The anchor

  • 1 cfs is about 0.028 m3/s
  • So 1000 cfs must be about 28 m3/s
  • 283 m3/s would rival the Mississippi at low flow
  • The constant is ten times too large
SEES:4100 | Week 04 | 12
Silent Bugs

Magnitude Anchors to Memorize

  • 1 cfs is about 0.028 m3/s
  • 1 inch = 25.4 mm
  • Iowa River at Iowa City: roughly 100 to 40,000 cfs
  • Check one converted value against an anchor, every time
