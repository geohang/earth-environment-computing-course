Core Concept

From Flat Column to Grid

elevation = elev["elevation_m"].to_numpy().reshape(50, 50)

elevation.shape        # (50, 50)
elevation[0, 0]        # one corner cell
elevation[25, :]       # row 25: a west-east profile
elevation[:, 10]       # column 10: a south-north profile
  • reshape fills row by row: value 51 starts row two
  • Convention all semester: rows are y, columns are x
SEES:4100 | Week 05 | 5
Core Concept

Indexing a Grid

elevation[row, col] # NOT (x, y)
row = position along y (south to north)
col = position along x (west to east)
elevation[25:, :] = the northern half
elevation[25, :] = one terrain profile
  • The plotting habit of (x, y) fights this all week; say row-column out loud

Core Concept

Vectorization: No Loops for Arithmetic

temp_f = temp_c * 9 / 5 + 32        # whole 50x50 grid, one line

elevation.mean()                     # one number for the map
elevation.mean(axis=0)               # 50 column means: a profile
elevation.max() - elevation.min()    # total relief
  • The code reads like the equation
  • Aggregations collapse the grid: whole map, or one axis at a time

Masks

A Mask Is a Map of a Condition

high = elevation > np.percentile(elevation, 75)

high.sum()               # how many cells
high.mean()              # fraction of the area
temperature[high].mean() # temperature only where high
  • The mask has the same shape as the grid: it IS a map
  • Masks count, measure area, and select in one move
SEES:4100 | Week 05 | 9
Masks

Combining Conditions on Arrays

  • Use & and |, never the words and / or
  • Parentheses around every comparison
  • (temp < t25) & (elev > e75): cool AND high
  • Check mask.sum() before trusting any masked statistic
SEES:4100 | Week 05 | 10
Display

The Two Classic Grid Gotchas

1. Reshape order

  • Row-major filling, always
  • reshape(ny, nx), not (nx, ny)
  • Verify: check one corner value against the table

2. Image origin

  • imshow counts rows downward by default
  • origin="lower" restores map orientation
  • An upside-down landscape is obvious in a plot, invisible in print

Display

Every Gridded Figure, Same Rules

fig, ax = plt.subplots(figsize=(6, 5))
image = ax.imshow(elevation, origin="lower", cmap="terrain")
ax.set_xlabel("Grid column")
ax.set_ylabel("Grid row")
fig.colorbar(image, ax=ax, label="Elevation (m)")
  • A colorbar with units is the map's axis label

Gradients

Slope Needs Real Spacing

dz_dy, dz_dx = np.gradient(elevation, dy_m, dx_m)
dz_dx = elevation change per meter, west-east
dz_dy = elevation change per meter, south-north
dx_m, dy_m = grid spacing from the coordinate columns
slope = sqrt(dz_dx**2 + dz_dy**2)
  • Without spacing arguments the units are meters per grid cell: physically meaningless

Visual Summary

Three Sentences to Keep

Slice

A slice is a subregion of the map: elevation[25:, :] is the north half.

Mask

A mask is a map of a condition: where is it steep, high, or cold?

Gradient

A gradient with real spacing is terrain slope with real units.
