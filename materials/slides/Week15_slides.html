Module A

Seventeen Stations on One Map

sites = pd.read_csv(PROCESSED / "iowa_stream_sites_annual_flow.csv",
                    dtype={"site_no": str})
per_site = sites.groupby(["site_no", "latitude", "longitude",
                          "drainage_area_sqmi"], as_index=False)\
                ["mean_discharge_cfs"].mean()
ax.scatter(per_site["longitude"], per_site["latitude"],
           s=per_site["drainage_area_sqmi"] / 20,
           c=per_site["mean_discharge_cfs"], cmap="viridis")
  • Size = drainage area, color = mean flow
  • Useful for any project comparing places

Specific Discharge Flips the Story

specific_q = mean_discharge / drainage_area
raw flow: big rivers carry more water (no surprise)
per-area flow: which LANDSCAPES yield more water?
normalization turns size into science
units: cfs per square mile, or mm/day
  • The most useful single trick for multi-site projects

Module B

Anomalies in Six Lines

s = series.set_index("date").sort_index()
clim = s.groupby(s.index.month)["value"].mean()
s["anomaly"] = s["value"] - s.index.month.map(clim)

# raw plot answers: what happened?
# anomaly plot answers: was it unusual for the season?
  • Any observable minus its seasonal expectation
  • Useful for any project asking about unusual periods

Module C

Time-Split Validation in Six Lines

train, test = train_test_split_by_time(df, "date", "2024-01-01")
fit = linear_regression_summary(train[x], train[y])
pred_test = fit["intercept"] + fit["slope"] * test[x]
print("train RMSE:", rmse(train[y], fit["intercept"] + fit["slope"] * train[x]))
print("test RMSE: ", rmse(test[y], pred_test))
  • Report the score next to every map, fit, or hydrograph
  • Useful for any project that fits anything

Pitfalls

The Final-Week Classics, Named in Advance

Unlabeled figures

Figures added faster than they are labeled. Fix: checklist pass tonight.

Order-dependent notebook

Runs only in the order last edited. Fix: Restart and Run All now.

Overrun conclusions

"Proves" where evidence "suggests". Fix: calibrate the verbs.

The unexplainable section

One member cannot explain section 3. Fix: walk-throughs this week.
