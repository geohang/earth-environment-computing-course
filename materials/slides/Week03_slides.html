Earth & Environmental Computing | Week 03 | 2
Core Concept

One Decision, Three Branches

rain_mm = 12.0

if rain_mm >= 10:
    label = "wet"
elif rain_mm > 0:
    label = "damp"
else:
    label = "dry"

print(label)     # wet
  • Exactly one branch runs
  • Change rain_mm, watch the branch change
Earth & Environmental Computing | Week 03 | 3
Core Concept

Counters Remember Across Iterations

longest = 0
current = 0
for precip in precip_values:
    if precip < 1.0:
        current = current + 1
        longest = max(longest, current)
    else:
        current = 0     # forget this line and see the next slide
  • current tracks the run in progress; longest keeps the record
  • The reset in the else branch is where the logic lives

The Planted Bug

Core Concept

Branch Order Decides the Label

# A day with 15 mm rain AND a 33 deg C maximum:
if row["precipitation_mm"] >= 10:
    label = "wet"            # <- evaluation stops here
elif row["temp_max_c"] >= 32:
    label = "hot"            # never reached for this day
else:
    label = "ordinary"
  • elif chains stop at the first true branch
  • Wet-before-hot is a decision; the lab asks you to defend it
Earth & Environmental Computing | Week 03 | 6
Verification

Two Implementations, One Answer

Loop version

for each row: if hot and humid: count = count + 1

Vectorized version

((temp_max >= 30) & (humidity >= 70)).sum()

The counts must match. Agreement between independent implementations is the lab's built-in test.
Earth & Environmental Computing | Week 03 | 7
The Science

Thresholds Are Choices

Farmer

5 mm wets the topsoil: a useful rain.

Flood manager

25 mm in a day starts mattering downstream.

Climatologist

1 mm separates a wet day from a dry one in many indices.

Every event count in this lab depends on a threshold somebody chose.
