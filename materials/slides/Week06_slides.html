Earth & Environmental Computing | Week 06 | 23
Compare

Groupby Month vs Resample Month

groupby(month)

12 rows, the climatology

  • A typical year, month by month
  • Every May averaged together
  • s.groupby(s.index.month).mean()

resample("MS")

One row per actual month

  • The historical sequence
  • May 2019 stands alone
  • s.resample("MS").mean()
Conflating these two is the most common error of the week.

Worked Example

How Fast Does the River Answer the Rain?

Python
events = merged.nlargest(5, "precipitation_mm")
rows = []
for day, rain in zip(events["date"], events["precipitation_mm"]):
    w = flow.loc[day : day + pd.Timedelta(days=5)]
    rows.append({"date": day.date(), "rain_mm": round(rain, 1), "flow_day0": w.iloc[0],
                 "peak_cfs": w.max(), "days_to_peak": (w.idxmax() - day).days})
pd.DataFrame(rows)
Output

Daily vs Monthly Correlation, Rain to River

Python
daily_r = merged["precipitation_mm"].corr(merged["discharge_cfs"])

monthly = (merged.set_index("date").resample("MS")
                 .agg({"precipitation_mm": "sum", "discharge_cfs": "mean"}))

print(f"daily r = {daily_r:.3f}   monthly r = {monthly_r:.3f}")

daily r = 0.107   monthly r = 0.428
  • Same data, four times the correlation: flow answers rain days later, so same-day pairs miss the link
  • The aggregation choice changes the answer; state it in every figure caption

Pitfalls

Where This Week Goes Wrong

  • Single brackets when you meant a DataFrame, double when you meant a Series
  • Dates left as text: filters run and return the wrong rows
  • Resample without a datetime index
  • Precipitation averaged when it should be summed
  • Climatology table confused with the full-length column
  • Merge losses discovered three cells too late

Summary

Key Takeaways

  • A DataFrame is labeled columns sharing one index; check shape, dtypes, isna() first
  • [ ] selects columns, .loc selects by label or mask, .iloc by position
  • parse_dates first; .dt and a date index unlock the calendar
  • groupby = typical, resample = actual; the difference is the anomaly
  • Sum precipitation, average temperature
  • Count rows before and after every merge
