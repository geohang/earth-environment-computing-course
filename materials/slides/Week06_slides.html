Core Concept

Groupby Month vs Resample Month

groupby(month)

  • 12 rows, the climatology
  • A typical year, month by month
  • Every May averaged together

resample("MS")

  • One row per actual month
  • The historical sequence
  • May 2019 stands alone
Conflating these two is the most common error of the week.

Core Concept

Rolling Windows and Anomalies

s = stream.set_index("date").sort_index()
s["rolling_30d"] = s["discharge_cfs"].rolling(30, min_periods=15).mean()

clim = s.groupby(s.index.month)["discharge_cfs"].mean()
s["anomaly"] = s["discharge_cfs"] - s.index.month.map(clim)
  • Rolling smooths storms without snapping to calendar edges
  • Anomaly = observed minus what is normal for that month

Worked Example

How Fast Does the River Answer the Rain?

Given

The five largest daily rainfalls in the merged 2019-2025 record.

Solve

For each event, read flow on day 0 and the peak within the next five days.

Interpret

Days-to-peak column shows the watershed's response time, event by event.

Earth & Environmental Computing | Week 06 | 21
Live Code · Worked Example

The Event-Response Table, Computed

Python
merged = weather.merge(stream[["date", "discharge_cfs"]], on="date", how="inner")
flow   = stream.set_index("date")["discharge_cfs"]
events = merged.nlargest(5, "precipitation_mm")
rows = []
for day, rain in zip(events["date"], events["precipitation_mm"]):
    w = flow.loc[day : day + pd.Timedelta(days=5)]
    rows.append({"date": day.date(), "rain_mm": round(rain, 1),
                 "flow_day0": w.iloc[0], "peak_cfs": w.max(),
                 "days_to_peak": (w.idxmax() - day).days})
pd.DataFrame(rows)
Output
         date  rain_mm  flow_day0  peak_cfs  days_to_peak
0  2020-06-09     88.4     7700.0    7700.0             0
1  2024-06-20     67.3     2660.0    3600.0             4
2  2024-08-15     64.3     3070.0    3070.0             0
3  2024-04-02     59.4     1820.0    2210.0             1
4  2021-10-24     56.6      537.0    1240.0             5
  • Response ranges from 0 to 5 days; a day-5 peak sits on the window edge, so widen and recheck

Daily vs Monthly Correlation, Rain to River

Python
daily_r = merged["precipitation_mm"].corr(merged["discharge_cfs"])

monthly = (merged.set_index("date")
                 .resample("MS")
                 .agg({"precipitation_mm": "sum", "discharge_cfs": "mean"}))
monthly_r = monthly["precipitation_mm"].corr(monthly["discharge_cfs"])

print(f"daily r = {daily_r:.3f}   monthly r = {monthly_r:.3f}")
Output
daily r = 0.107   monthly r = 0.428
  • Same data, four times the correlation: flow answers rain days later, so same-day pairs miss the link
  • Aggregation choice changes the answer, so state it in every figure caption
