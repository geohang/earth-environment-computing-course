Pseudocode

The Centered Moving Average, in English

for each position i in the series:
    start = i minus half the window (not below 0)
    end   = i plus half the window (not past the end)
    output[i] = mean of values from start to end
  • Two decisions hide in four lines: placement and edges
  • Circle them before anyone types Python
Earth & Environmental Computing | Week 09 | 6
Implementation

From Pseudocode to Python

def moving_average_centered(values, window):
    half = window // 2
    out = []
    for i in range(len(values)):
        start = max(0, i - half)
        end = min(len(values), i + half + 1)
        out.append(np.mean(values[start:end]))
    return np.array(out)
  • max and min ARE the edge policy, written down
  • The +1 in end is where off-by-one bugs live
Earth & Environmental Computing | Week 09 | 7
The Case Study

Trailing vs Centered: Timing Is Science

Trailing window

  • Uses only the past
  • Smoothed peaks arrive LATE
  • Right choice for real-time monitoring

Centered window

  • Uses both sides
  • Peaks stay in place
  • Right choice for reanalysis of finished records
If event timing is the question, window placement is a scientific choice.

Edges

The Boundary Problem

  • First value of a 14-day trailing mean: one day of data
  • Options: shrink the window, pad, or refuse to report
  • Each is defensible; silence about the choice is not
  • Most published smoothing artifacts live in the first window-width

Verification

Three Rungs of Verification

1

Tiny input

[1..5], window 3: the middle value must be exactly 3. Hand-checkable truth.

2

Trusted twin

np.allclose against pandas rolling on real data. Independent agreement.

3

Manufactured truth

Delete known data, reconstruct, score. The lab gap experiment.

Verification

The Tiny Test, Live

check = moving_average_centered(np.array([1., 2., 3., 4., 5.]), 3)
assert check[2] == 3.0

trusted = pd.Series([1., 2., 3., 4., 5.]).rolling(
    3, center=True, min_periods=1).mean()
print(np.allclose(check, trusted))    # True
  • Five numbers settle placement, edges, and arithmetic at once

Earth & Environmental Computing | Week 09 | 15
Filter Choice

Mean vs Median on a Spiky River

Moving mean

  • Every value votes, weighted equally
  • One flood day drags the whole window up
  • Smooth result, smeared peaks

Moving median

  • The middle value wins
  • Single-day spikes barely register
  • Preserves edges, resists outliers
Studio session practice: run both on the same flood and compare peak heights.

Performance Note

When the Loop Becomes the Bottleneck

  • Your loop: clear, correct, fine for 4,000 days
  • np.convolve or pandas rolling: the same math, vectorized
  • Rule: make it right first, fast only if needed
  • Clarity is a feature; premature speed is a bug generator
