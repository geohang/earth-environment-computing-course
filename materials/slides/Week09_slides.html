Step 3 · Pseudocode

Turn What Your Hands Did Into Steps

By hand, you

moved to each day in turn,
found the first and last day of its window,
averaged the values between them,
wrote the result under that day.

In steps

half = window // 2
for each day i in the series:
    start = i - half
    end   = i + half
    output[i] = mean of values from start to end
return output
Each line is one small job. Any line you cannot write yet is a sub-problem to design on its own.

Step 5 · Code

Translate, Line by Line, Decisions Included

The code

def moving_average_centered(values, window):
    if window % 2 == 0:
        raise ValueError("window must be odd")
    half = window // 2
    out = []
    for i in range(len(values)):
        start = max(0, i - half)
        end = min(len(values), i + half + 1)
        out.append(np.mean(values[start:end]))
    return np.array(out)

On the toy river

moving_average_centered(
    np.array([1., 1, 1, 10, 1, 1, 1]), 3)

[1. 1. 4. 4. 4. 1. 1.]

The two max/min lines are the step 4 decisions. Without step 4 they would not exist. The + 1 is pure Python: a slice stops before its end. The output matches the row you computed by hand in step 2.

Step 7 · The new design in code

A Running Sum: From n·w Work to About 2n

The code

def moving_average_running(values, window):
    if window % 2 == 0:
        raise ValueError("window must be odd")
    half = window // 2
    n = len(values)
    out = np.empty(n)
    total = values[:half + 1].sum()
    count = len(values[:half + 1])
    out[0] = total / count
    for i in range(1, n):
        if i + half < n:            # a day enters
            total += values[i + half]
            count += 1
        if i - half - 1 >= 0:       # a day leaves
            total -= values[i - half - 1]
            count -= 1
        out[i] = total / count
    return out

What it bought

w = 365: 1,433,264 additions become about 8,000.

count keeps the shrink decision from step 4: edges still average only the days that exist.

Harder to read than step 5. That is the price of speed.

Steps 3 and 4 · Your turn

Pseudocode, Then Hunt for the Gaps That Break It

The plan

for each run of missing days, first to last:
    left  = value on day first - 1
    right = value on day last + 1
    L     = last - first + 1
    for k = 1 to L:
        day = first + k - 1
        out[day] = left + (right - left)
                   * k / (L + 1)
