Code as a scientific tool

01

Reproducible work

Use NumPy and pandas to work with weather, streamflow, water-quality, and gridded data.

Scientific reasoning

AI

Responsible tool use

When allowed, AI tools may support debugging, refactoring, comments, tests, and documentation. Disclose meaningful assistance, run and review every line, verify outputs, and be ready to explain your work.

Never use AI to fabricate data, citations, results, or interpretations. Never upload restricted data.
